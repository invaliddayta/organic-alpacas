# GenAI interaction record

One markdown file per session in `phase1/` (later `phase2/`), named `YYYY-MM-DD-topic.md`.

Each entry:

- **Tool:** model / tool used
- **Prompt:** the important prompt(s), shortened if long
- **Result:** what the AI suggested or generated
- **Decision:** accepted / modified / rejected, and why
- **Effect:** how it changed the next analysis step

Failure patterns and best practices also go into `ai_reflection_midpoint.md`.
